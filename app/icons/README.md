# Icons and cursors

Toolbar icons (`app/icons/*.svg`, 24×24) and tool cursors (`app/cursors/*.svg`, 32×32, hotspots in
`app/cursors/hotspots.json`) are drawn for Dogeometric to match SketchUp 2021's look: the same subject, layout and
colours, so the tools are recognisable at a glance. They are new drawings made by hand, not copies of Trimble's
files. Do not add Trimble's own artwork to this repository.
