STEP files made with FreeCAD 1.1 (`Part.makeBox`, `makeCylinder`, `makeSphere`, `makeTorus`, `makeCone`, a loft between a
circle and an ellipse, a B-spline profile extruded and one revolved, and an assembly of boxes and cylinders) to check the STEP importer against FreeCAD's volumes. `offset.step` is the loft's side offset 2 mm (an OFFSET_SURFACE).
